# Правила работы с проектом

## Авторство коммитов и pull request

- Создавать коммиты и pull request только от имени владельца проекта.
- Для коммитов использовать настроенные владельцем `git user.name` и
  `git user.email`; не подставлять имя или адрес Codex, OpenAI либо бота.
- Не добавлять `Co-authored-by` для Codex, OpenAI или других AI-ассистентов.
- Не добавлять подписи, упоминания участия или отметки генерации AI в
  сообщениях коммитов, заголовках и описаниях pull request.
- Создавать pull request через учётную запись владельца проекта.
- Не менять настройки авторства Git без прямого поручения владельца.
- Не создавать коммит или pull request только из-за наличия этих правил:
  их создание должно входить в порученную задачу.
