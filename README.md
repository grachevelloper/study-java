# Информационная система интернет-магазина

Консольное приложение на Java 21 для работы с покупателями, товарами и
заказами.

## Возможности

- управление покупателями и товарами;
- создание и изменение заказов;
- поиск, фильтрация и сортировка заказов;
- изменение статуса заказа;
- просмотр статистики;
- экспорт данных в Excel.

## Требования

- Java 21;
- Maven;
- Docker.

## Запуск

При первом запуске создайте файл настроек:

```bash
cp .env.example .env
```

Запустите базу данных и приложение:

```bash
docker compose up -d --wait
mvn clean package
java -jar target/online-store.jar
```

## Проверка

```bash
mvn clean verify
```

## Остановка

```bash
docker compose down
```
